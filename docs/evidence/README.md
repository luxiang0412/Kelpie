# 证据库（docs/evidence）

报告里引用的截图与原始数据都在这里。**不要**把新证据散放在别处，也不要把未引用的截图提交进来。

## 命名约定

| 前缀 | 含义 |
| --- | --- |
| `m1-*` `m2-*` `m2a-*` `m2b-*` `m2c1-*` `m2c2-*` `m2c2v-*` | 各里程碑验收截图 |
| `ux0*` | UX-D0 改造（Before/After 对照、矩阵 P1–P8） |
| `real-*` | **真机**（Redmi 22021211RC / MIUI / Android 14） |
| `claude-*` | Claude 适配（会话定位、工具卡、表格） |
| `rel0*` | 发版验收（0.1.0 / 0.1.1） |
| `s1-*` … `s5-*` | Spike 1–5 实测原始数据（CSV/日志） |

## 来源标记规则

- 文件名或所在报告必须标注来源：`真机` / `AVD（herdr_m2c1, android-34 x86_64）` / `Fixture 页面`；
- AVD 数据**不得**当作真机性能结论（见 ISSUES I-74/I-78/I-83）；
- 截图必须同 Fixture / 同主题 / 同宽度 / 同字号才可对比。
